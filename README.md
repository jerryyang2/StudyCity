# StudyCity 網頁教室

支援學生附上完成說明、老師／家長留下文字回饋，以及重新提交與確認歷程。說明與回饋最多 1000 個字元；只有提交本人及群組建立者可查看。0.6 版整理任務狀態、搜尋、排序與指定任務審核；沿用 0.5 版獎勵領取確認、取消原因、原價退還與狀態篩選。0.6 不變更後端或資料庫結構；從更舊服務升級時請先保存資料庫副本。GitHub Pages 仍是靜態網頁，實際教室資料需連線到自己啟動的本機服務。

StudyCity 的獨立網站與本機教室服務。老師先提交開通申請，經管理者確認後，可自行建立教室、發布任務與管理商城；學生註冊後以邀請碼加入。

## 使用範圍

- GitHub Pages 提供網站與老師開通申請入口。
- 老師申請以 Google 表單私密收件，管理者可接收新回覆通知；申請資料不存入本儲存庫。
- 帳號、教室、任務、審核、積分、商品及排行榜目前在本機服務使用，尚未部署線上多人後端。
- 老師帳號不開放自行註冊；網站角色選項不能繞過服務端審核規則。

## 在自己的 Mac 啟動教室

需要 Python 3.9 以上，使用標準函式庫，不需安裝第三方套件：

```sh
python3 Server/server.py
```

在瀏覽器開啟 `http://localhost:8787`。資料保存在已排除的 `LocalOnly/server.sqlite`，不要將資料庫、紀錄、憑證或實際學生資料上傳 GitHub。

管理者確認老師申請後，在同一台服務主機建立帳號：

```sh
python3 Server/admin.py --username teacher_alias --alias "老師代稱"
```

密碼採隱藏輸入，不放命令列參數。開通資訊透過另行確認的私人管道交付，不填在公開 Issues。

## 教室功能

- 老師與家長建立各自群組，分享或更換邀請碼。
- 學生提交任務；群組建立者確認後發放群組積分。
- 學生依任務狀態與名稱查找，選擇優先處理、截止時間或名稱排序；等待確認及已通過任務以中性時間呈現，逾期仍可提交。
- 建立者查看每項任務的歷史提交筆數，開啟該項任務的審核清單；依學生代稱／任務名稱搜尋、狀態篩選及最近更新時間排序。
- 商城商品由建立者決定名稱、內容、價格、庫存與上下架。
- 積分與庫存以交易保存，審核與重送兌換防重，歷史兌換保留當時商品條件。
- 獎勵提供與領取紀錄、學生積分收支、自願參加的群組排行榜。
- 建立者確認已提供獎勵；尚未提供時可填寫取消原因，依原兌換價格退還積分。取消與確認提供互斥，重送不重複退還。
- 領取紀錄顯示狀態、當時商品內容、取消原因及結案時間；全部待提供紀錄保留可見，已結案顯示最近 200 筆，另列完整狀態總數。
- 新版兌換會核對確認價格，商品編輯核對預期庫存；資料在操作期間已變更時，要求重新整理確認。
- 學生私人城市與各群組積分分開，不會上傳私人 App 任務。

取消退還不增加排行榜的累積努力積分。庫存只在新紀錄明確扣過限量份數、商品目前仍限量且未達上限時自動回補一份；舊版紀錄或條件不符時不自動回補，建立者應依實際可提供份數調整。舊紀錄沒有的結案時間保持未知，不補造時間。新版前端連到舊服務時會提示更新，保留原本的領取確認流程。

任務提交筆數依永久任務 ID 歸屬，包含已退出成員的歷史紀錄，不表示目前成員完成率。舊回應缺少任務 ID 時不以相同名稱合併，並提示無法完整歸屬。審核時間代表重新提交或最近處理，並非第一次提交；期限標籤定時刷新只影響畫面，不新增通知或改變獎勵。

## 網站設定

前端在 `docs`，`docs/config.js` 只存公開的 API 位址與申請表作答網址，不放管理信箱、密碼、權杖或表單編輯連結。

目前 `apiBase` 留空：本機會連同源服務，GitHub Pages 則顯示服務尚未連線。若日後配置 HTTPS 後端，需另設定主機與允許的前端 Origin，再更新 API 位址；不要把前端本機儲存當成多人教室。

GitHub Pages 來源為 `main` 的 `/docs`。Pages 無法執行 Python 或資料庫。

本機服務預設只監聽 127.0.0.1。正式對外運行需另外規劃 HTTPS、服務維運、備份與個資處理；本儲存庫不包含登入憑證、資料庫或私人開發歷史。
